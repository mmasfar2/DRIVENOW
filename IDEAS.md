## Google Drive upload integration
Let users pick a file directly from Google Drive (via Google's Picker API) on
upload fields (insurance docs, license scans, inspection photos, etc.),
instead of only being able to choose a file from the local device.

Requires: a Google Cloud Console project with OAuth credentials (Client ID)
and the Drive API enabled — account-level setup only the owner can do before
this can be built.
